# Build a Star Wars Copilot Workshop

Hello there!

This repo now contains two versions of the Star Wars Copilot workshop:

- [C# workshop](./csharp/README.md)
- [Python workshop](./python/README.md)

Both workshops follow the same 8-lesson progression, from basic chat to tools, MCP, RAG, multimodal AI, and agents.

## Repository structure

- `csharp/` - original C# workshop content
- `python/` - Python port of the workshop
